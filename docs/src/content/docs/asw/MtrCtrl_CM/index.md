# Motor Control (Current Mode)

*Repository directory: `MtrCtrl_CM`*

:::tip[Origin: Custom — Nexteer logic on Vector-generated scaffold]
Application logic is Nexteer in-house; the RTE interaction scaffold was generated by the Vector MICROSAR RTE Generator / DaVinci tooling (generator banner in file header, `autosar/` model, `utp/contract` RTE stubs).
:::

## Purpose and responsibility

This module takes the cumulative motor position and determines the motor direction (using a previously saved state variable and a calibration constant for hysteresis).
