# Sine-Voltage Drive Diagnostics

*Repository directory: `SVDiag`*

:::tip[Origin: Custom — Nexteer logic on Vector-generated scaffold]
Application logic is Nexteer in-house; the RTE interaction scaffold was generated by the Vector MICROSAR RTE Generator / DaVinci tooling (generator banner in file header, `autosar/` model, `utp/contract` RTE stubs).
:::

## Purpose and responsibility

This module compares the commanded duty cycle to each phase with the feedback from the NHET module.

> **Note:** this directory mixes AUTOSAR naming prefixes (`Ap_`, `Sa_`); it is grouped under Application Software (ASW) by its primary role, with cross-references where relevant.
