# Digital Column Position Sensor Interface (I²C)

*Repository directory: `DigColPs`*

:::tip[Origin: Custom — Nexteer logic on Vector-generated scaffold]
Application logic is Nexteer in-house; the RTE interaction scaffold was generated by the Vector MICROSAR RTE Generator / DaVinci tooling (generator banner in file header, `autosar/` model, `utp/contract` RTE stubs).

## Purpose and responsibility

The digital column position sensor component reads sensor data from the digital column position sensor interface and processes the raw angle data into handwheel position in degrees and determines the validity of that angle.
