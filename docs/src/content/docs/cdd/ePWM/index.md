# Enhanced PWM and NHET Driver

*Repository directory: `ePWM`*

:::tip[Origin: Custom — Nexteer logic on Vector-generated scaffold]
Application logic is Nexteer in-house; the RTE interaction scaffold was generated by the Vector MICROSAR RTE Generator / DaVinci tooling (generator banner in file header, `autosar/` model, `utp/contract` RTE stubs).
:::

## Purpose and responsibility

This module implements NHET1 and HTU1 initialization per ES-34B NHET1 subfunctions, and NHET2 initialization, currently not documented in an FDD.

> **Note:** this directory mixes AUTOSAR naming prefixes (`Ap_`, `Cd_`); it is grouped under Complex Device Drivers (CDD) by its primary role, with cross-references where relevant.

## Typical usage

Call pattern derived from the detected entry points (exact runnable mapping is defined by the RTE configuration in the ECU project):

```c
Nhet_Init1();            /* once, during startup */
ePWM_Init1();            /* once, during startup */
ePWM2_Per1(/* ports */);  /* periodically, via RTE runnable */
Nhet1_Per1(/* ports */);  /* periodically, via RTE runnable */
Nhet1_Per2(/* ports */);  /* periodically, via RTE runnable */
Nhet1_Per3(/* ports */);  /* periodically, via RTE runnable */
ePWM_Per1(/* ports */);  /* periodically, via RTE runnable */
```
